# Google Gemini Experiment

This directory hosts the empirical run for **Google Gemini** (1.5 Pro / Ultra / Gemini Experimental).

## Setup
1. Copy the benchmark prompt from [`../../benchmark/prompt.md`](../../benchmark/prompt.md).
2. Paste into Gemini (`gemini.google.com/app` or AI Studio).
3. Save:
   - `response.md`: The raw response text and design rationale generated by Gemini.
   - `order_service.py` (or newly created files): The code modifications provided by Gemini.
   - `evaluation.md`: Rubric evaluation analyzing whether Gemini chose the boolean flag, class bloat, or clean service separation.
