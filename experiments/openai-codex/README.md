# OpenAI Codex / Sol Experiment

This directory hosts the empirical run for **OpenAI Codex / o1 / GPT-4o / Sol**.

## Setup
1. Copy the benchmark prompt from [`../../benchmark/prompt.md`](../../benchmark/prompt.md).
2. Paste into OpenAI Codex / ChatGPT / API session.
3. Save:
   - `response.md`: The raw response text and design rationale generated by Codex.
   - `order_service.py` (or newly created files): The code modifications provided by Codex.
   - `evaluation.md`: Rubric evaluation analyzing whether Codex chose the boolean flag, class bloat, or clean service separation.
